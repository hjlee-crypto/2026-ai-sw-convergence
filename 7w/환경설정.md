## Ollama 설치

## STEP 0-5. Ollama 설치

Ollama Windows 버전을 설치합니다.

> 
> 
> 
> 공식 사이트:
> 
> `https://ollama.com/download/windows`
> 
> Ollama 실행 중 계정 생성 화면이 나오면:
> 
> `No thanks, I'll use Ollama locally`
> 로컬 Ollama를 사용하므로 회원가입하지 않아도 됩니다.
> 

설치가 끝나면 VS Code 터미널을 새로 열고 확인합니다.

```
ollama --version
```

정상 예:

```
ollama version is 0.40.2
```

---

## STEP 0-6. Gemma 모델 다운로드

이번 실습에서는 다음 모델을 사용합니다.

```
gemma3:4b
```

터미널에서:

```
ollama pull gemma3:4b
```

모델 다운로드가 완료될 때까지 기다립니다.

### **다운로드 진행 예**

`pulling manifest
pulling ...
verifying sha256 digest
writing manifest
success`

마지막에:

`success`

가 나오면 완료입니다.

---

## STEP 0-7. Ollama 모델 확인

```
ollama list
```

정상적으로 설치되었다면 다음과 같이 나타납니다.

```
NAME
gemma3:4b
```

---

## STEP 0-8. Ollama 직접 실행 확인

Python과 연결하기 전에 Ollama 자체가 정상적으로 동작하는지 확인합니다.

```
ollama run gemma3:4b
```

예를 들어:

```
>>> 안녕하세요.
```

라고 입력합니다.

답변이 나오면 정상입니다.

종료:

```
/bye
```

# Python 가상환경 설정

## STEP 0-9. 7w 폴더로 이동

```
cd C:\2026-open\7w
```

현재 위치가 다음과 같아야 합니다.

```
PS C:\2026-open\7w>
```

## STEP 0-10. 가상환경 생성

```
python -m venv .venv
```

실행 후 `7w` 폴더 안에 다음 폴더가 생성됩니다.

```
7w
└─ .venv
```

가상환경은 **이번 실습에 필요한 Python 패키지를 별도로 관리하기 위한 공간**입니다.

## STEP 0-11. 가상환경 활성화

PowerShell에서:

```
.\.venv\Scripts\Activate.ps1
```

정상적으로 활성화되면 터미널 앞부분이 바뀝니다.

```
(.venv) PS C:\2026-open\7w>
```

이후 실습에서는 가급적 **`(.venv)`가 표시된 상태에서 명령을 실행**합니다.

# Python 패키지 설치

## STEP 0-12. requirements.txt 작성

`7w` 폴더에 다음 파일을 만듭니다.

```
requirements.txt
```

내용:

```
streamlit==1.65.0

langchain-community
langchain-text-splitters
langchain-huggingface
langchain-chroma
langchain-ollama

chromadb
sentence-transformers
pypdf
torchvision
```

`torchvision`은 Streamlit과 `transformers`를 함께 사용할 때 발생할 수 있는 관련 모듈 오류를 방지하기 위해 포함합니다.

---

## STEP 0-13. pip 업데이트

가상환경이 활성화된 상태에서 실행합니다.

```
(.venv) PS C:\2026-open\7w>python -m pip install --upgrade pip
```

---

## STEP 0-14. 필요한 패키지 한 번에 설치

```
(.venv) PS C:\2026-open\7w>python -m pip install -r requirements.txt
```

처음 설치할 때는 시간이 다소 걸릴 수 있습니다.

---

## STEP 0-15. 패키지 설치 확인

```
(.venv) PS C:\2026-open\7w>python -m pip list
```

다음과 같은 패키지들이 설치되어 있는지 확인합니다.

```

# 환경설정 완료 확인

최종적으로 다음 항목이 모두 확인되면 됩니다.

> 
> 
> 
> ```java
> Python 설치 완료
> ↓
> 7w 가상환경 생성
> ↓
> 가상환경 활성화
> ↓
> requirements.txt 작성
> ↓
> 패키지 설치
> ↓
> torchvision 확인
> ↓
> Streamlit 확인
> ↓
> Ollama 확인
> ↓
> gemma3:4b 확인
> ```
> 
> 터미널:
> 
> `(.venv) PS C:\2026-open\7w>`
> 
> 그리고 아래 명령이 모두 정상 동작해야 합니다.
> 
> ```
> python --version
> ollama --version
> ollama list
> streamlit --version
> ```
> 

| 확인 항목 | 확인 방법 | 성공 기준 |
| --- | --- | --- |
| VS Code | 프로그램 실행 | 프로젝트 폴더 표시 |
| Python | `python --version` | Python 3.12.x |
| Python 실행 | `python test.py` | `hello` 출력 |
| Ollama | `ollama --version` | 버전 표시 |
| Gemma | `ollama list` | `gemma3:4b` 표시 |
| Gemma 실행 | `ollama run gemma3:4b` | 질문에 답변 |
| 가상환경 | 터미널 확인 | `(.venv)` 표시 |
| 패키지 | `python -m pip list` | 필요한 패키지 표시 |
| Streamlit | `streamlit --version` | 버전 표시 |

이 상태가 되면 비로소 **STEP 1 실습**으로 넘어갑니다.

```
python step1_ollama.py
```

전체 흐름을 한 줄로 줄이면:

```
VS Code 설치
→ Python 설치
→ Python 실행 확인
→ Ollama 설치
→ Gemma 모델 다운로드
→ 7w 가상환경 생성
→ requirements.txt 작성
→ 패키지 설치
→ 설치 확인
→ STEP 1 실행
```
