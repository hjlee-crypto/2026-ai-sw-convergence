step3_basic_rag.py은 **문서 검색 결과를 Ollama에 전달해서, 문서 기반 답변을 1회 생성하는 단계**입니다.

1. 6w/data의 공지*.pdf 파일을 불러옵니다.
2. PDF 내용을 Chunk로 나눕니다.
3. Chunk를 Embedding합니다.
4. Chroma Vector DB를 생성합니다.
5. 사용자의 질문을 Retriever에 전달합니다.
6. 질문과 관련된 Chunk 3개를 검색합니다.
7. 검색된 Chunk 내용을 하나의 context로 합칩니다.
8. context + 질문을 Prompt로 구성합니다.
9. Ollama의 gemma3:4b에 Prompt를 전달합니다.
10. 문서 내용을 근거로 RAG 답변을 생성합니다.
11. 검색된 문서명과 최종 답변을 터미널에 출력합니다.

흐름보면:

`질문
   ↓
Vector DB 검색
   ↓
관련 Chunk 3개
   ↓
검색된 문서 내용 결합
   ↓
Prompt 생성
   ↓
Ollama
   ↓
문서 기반 답변`

STEP 3은 **한 번 질문하고 한 번 답하는 Basic RAG**입니다. 이전 대화 내용은 사용하지 않습니다.
