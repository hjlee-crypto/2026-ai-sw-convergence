1. `6w/data` 폴더의 `공지*.pdf` 파일을 불러옵니다.
2. PDF 내용을 여러 개의 Chunk로 나눕니다.
3. Chunk를 Embedding하여 Chroma Vector DB에 저장합니다.
4. 사용자가 질문을 입력합니다.
5. 이전 질문이 있으면 **이전 질문 + 현재 질문**을 검색 Query로 만듭니다.
6. Retriever가 관련 Chunk를 검색합니다.
7. 이전 대화 내용과 검색된 문서를 Prompt에 넣습니다.
8. Ollama의 `gemma3:4b`가 문서를 근거로 답변을 생성합니다.
9. 질문과 답변을 `chat_history`에 저장합니다.
10. 다음 질문을 입력받아 같은 과정을 반복합니다.
11. `exit`를 입력하면 종료합니다.

흐름:

```
사용자 질문
   ↓
이전 질문 확인
   ↓
검색 Query 생성
   ↓
Vector DB 검색
   ↓
관련 문서 Chunk 검색
   ↓
이전 대화 + 검색 문서 + 현재 질문
   ↓
Ollama
   ↓
답변 생성
   ↓
대화 기록 저장
   ↓
다음 질문
```
